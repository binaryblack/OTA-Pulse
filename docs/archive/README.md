# Archived Documentation

These are historical, point-in-time documents kept for the audit trail. They are **not
maintained** and must **not** be treated as current: they may describe designs that were
abandoned, code that has since been deleted, or commands/paths that no longer exist.

For the live state of this repository, see:

- [`README.md`](../../README.md) — repository overview and structure
- [`docs/`](../) — current guides: `INTEGRATION.md`, `CONFIGURATION.md`, `API.md`,
  `SECURITY.md`, `TROUBLESHOOTING.md`

Files here keep their original relative path under `docs/archive/` (e.g.
`docs/archive/soc-ota-agent/QUICK_REFERENCE.md` was `soc-ota-agent/QUICK_REFERENCE.md`).

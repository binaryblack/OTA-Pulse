# Contributing to OTAPulse

Thank you for your interest in contributing to OTAPulse.

## Reporting Issues

If you encounter bugs or have feature requests, please create an issue with:

- Clear description of the problem or feature
- Steps to reproduce (for bugs)
- Environment details (device type, OS version, agent version)

## Pull Requests

We welcome pull requests for bug fixes and improvements.

### Guidelines

1. **Sign your commits** - Use `git commit -s` to add a sign-off line
2. **Keep commits focused** - Each commit should address one logical change
3. **Follow existing style** - Match the code style of the existing codebase
4. **Add tests** - Include tests for new functionality
5. **Update documentation** - Keep docs in sync with code changes

### Commit Message Format

```
type: brief description

Detailed explanation if needed.

Signed-off-by: Your Name <your.email@example.com>
```

Types: `fix`, `feat`, `docs`, `test`, `refactor`
